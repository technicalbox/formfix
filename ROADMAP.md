# Roadmap — FormFix

## Phase 1 — MVP (NOW)

**Goal**: Working utility with core tools and verified exam presets.

- [x] Project setup (Astro + dependencies)
- [x] Documentation system (18 MD files)
- [ ] Design system (CSS custom properties)
- [ ] Image processing engine (resize, compress, convert)
- [ ] Crop tool (Cropper.js integration)
- [ ] Validation engine
- [ ] Homepage
- [ ] Generic tool pages (resize, crop, compress, convert)
- [ ] Exam preset system
- [ ] Exam SEO pages (SSC, UPSC, NEET, JEE, IBPS, RRB)
- [ ] Compression target pages (20KB, 50KB, 100KB, 200KB)
- [ ] SEO infrastructure (sitemap, robots, structured data)
- [ ] Mobile-responsive layout
- [ ] Privacy-first architecture verification
- [ ] Production build

## Phase 2 — Launch (NEXT)

**Goal**: Production deployment with monitoring.

- [ ] Deploy to Cloudflare Pages
- [ ] Custom domain setup
- [ ] HTTPS verification
- [ ] Performance audit and fixes
- [ ] Cloudflare Web Analytics (privacy-respecting)
- [ ] Error monitoring (if needed)
- [ ] Submit sitemap to Google Search Console
- [ ] Submit to Bing Webmaster Tools

## Phase 3 — SEO Expansion (LATER)

**Goal**: Expand coverage based on search demand data.

- [ ] Analyze Search Console data for new keyword opportunities
- [ ] Add exam presets with verified demand (GATE, CAT, CLAT, etc.)
- [ ] Add state-level exam presets (MPSC, UPPSC, etc.)
- [ ] Add university admission presets
- [ ] Add scholarship portal presets
- [ ] Blog/guide content for high-volume informational queries

## Phase 4 — Additional Exams (LATER)

**Goal**: Comprehensive exam coverage.

- [ ] Verify and add 20+ additional exam presets
- [ ] Banking exams (SBI PO, RBI Grade B)
- [ ] Defence exams (NDA, CDS, AFCAT)
- [ ] Teaching exams (CTET, TET)
- [ ] State PSC exams
- [ ] University entrance exams

## Phase 5 — Additional Document Tools (LATER)

**Goal**: Expand beyond photos and signatures.

- [ ] PDF compression
- [ ] PDF to image conversion
- [ ] Background removal (client-side ML)
- [ ] Batch processing
- [ ] Signature pad (draw signature in browser)
- [ ] Document scanner (camera-based)

## Phase 6 — Optimization (LATER)

**Goal**: Performance and revenue optimization.

- [ ] Ad integration (non-intrusive placements)
- [ ] A/B testing for conversion optimization
- [ ] PWA support (offline capability)
- [ ] Hindi and regional language UI
- [ ] User preferences (remember last exam preset)
- [ ] Performance optimization for low-end devices
- [ ] WebAssembly-powered processing (if Canvas API becomes a bottleneck)
