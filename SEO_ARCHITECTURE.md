# SEO Architecture — FormFix

## Search Intent

FormFix targets users with an immediate task: making a file compliant for an application portal. Every search query we target has a transactional or problem-solving intent.

### Primary Keyword Clusters

1. **Exam + photo resizer**: "SSC photo resizer", "UPSC photo size", "NEET photo requirements"
2. **Exam + signature resizer**: "SSC signature size", "IBPS signature format"
3. **Compress to specific KB**: "compress image to 50kb", "reduce image size to 20kb"
4. **Generic resize/compress**: "resize image online", "compress jpg online" (high competition, lower priority)

### URL Rules
- Flat URL structure (no `/exam/ssc/photo/`)
- Hyphens as word separators
- Lowercase only
- No trailing slashes
- Canonical URL on every page

## Page Templates

### 1. Exam Photo/Signature Page
- **H1**: "[Exam Name] Photo/Signature Resizer"
- **Requirements section**: Official specs with source link
- **Working tool**: Upload → process → validate → download
- **FAQ**: 4–6 exam-specific questions
- **Related tools**: Links to other exam pages and generic tools
- **Guidelines**: Official submission guidelines

### 2. Compression Target Page
- **H1**: "Compress Image to ≤ [X] KB"
- **Working tool**: Upload → set target (pre-filled) → compress → download
- **Common uses**: Which exams need this size
- **FAQ**: 3–4 compression-specific questions
- **Related pages**: Other compression targets, exam pages

### 3. Generic Tool Page
- **H1**: "[Tool Name] — Free Online Tool"
- **Working tool**: Full-featured tool
- **How it works**: Step-by-step
- **Exam presets**: Quick links to preset versions

## Metadata Strategy

### Title Format
- Homepage: `FormFix — Fix Photos, Signatures & Documents for Application Forms`
- Exam pages: `[Exam] Photo Resizer — Resize & Compress to Official Requirements | FormFix`
- Compression: `Compress Image to ≤ [X] KB — Free Online Tool | FormFix`
- Tool pages: `[Tool Name] — Free Online [Tool] | FormFix`

### Description Format
- Include the primary keyword naturally
- State the tool's function
- Mention "in your browser" (privacy differentiator)
- Under 155 characters

### Example
```
Title: SSC Photo Resizer — Resize & Compress to Official Requirements | FormFix
Description: Resize and compress your photo for SSC CGL, CHSL, and GD applications. Meet official size and format requirements. Processed in your browser — files never uploaded.
```

## Canonical Strategy

- Every page has a canonical URL pointing to itself
- No duplicate content across pages (each has a unique tool configuration)
- No www/non-www confusion (pick one, redirect the other)

## Indexation Rules

- All tool pages are indexable
- No thin content pages — every page has a working tool
- No auto-generated pages without verified search demand
- Pages with `status: "needs-verification"` presets display a disclaimer but are still indexable

## Thin Content Prevention

Every page must have:
1. A working tool (not just text)
2. Unique, exam-specific content (requirements, guidelines, FAQ)
3. Official source links
4. At least 300 words of useful, non-duplicated content

## Page Creation Rule

A new programmatic page is created ONLY when:
1. There is verified search demand (keyword research)
2. The page would have a working tool with meaningful differentiation
3. The requirement data is verified or clearly marked as unverified
4. The page would not duplicate an existing page's function

Do NOT mass-generate pages. Quality over quantity.
